# Smart City Network Infrastructure

A comprehensive smart city network topology designed and implemented using Huawei networking technologies. The project integrates multiple city services into a structured, secure, and scalable network infrastructure.

## Project Overview

The network connects multiple smart-city sectors, including:

* Healthcare
* Security & Surveillance
* Utilities
* Retail & Commercial
* Smart Building
* Residential
* Smart Parking

The project demonstrates practical implementation of VLAN segmentation, inter-VLAN routing, routing protocols, network security, redundancy, IP address management, and network administration.

## Technologies Used

* VLAN
* Router on a Stick (ROAS)
* ACL
* DHCP
* DHCP Relay
* STP / RSTP
* Eth-Trunk / LACP
* Static Routing
* RIP
* OSPF
* VLSM / Subnetting
* AAA
* Telnet
* FTP
* Console Security
* NDP / NTDP

## Network Sections

### 1. Healthcare Network

Implements VLAN segmentation, inter-VLAN routing, STP, link aggregation, AAA, Telnet, console security, and NDP/NTDP.

### 2. Security & Surveillance Network

Uses Router on a Stick, VLANs, AAA, Telnet, and console security to support secure network access and communication.

### 3. Utilities Network

Implements centralized DHCP, DHCP relay, static routing, AAA, Telnet, and VTY-based remote management.

### 4. Retail & Commercial Network

Uses VLAN segmentation and DHCP services to separate departments and automate IP address allocation.

### 5. Smart Building Network

Implements VLANs and ACLs to control traffic and provide network segmentation and access control.

### 6. Residential Network

Uses STP, link aggregation, and Eth-Trunk with LACP to provide redundancy and improved bandwidth.

### 7. Smart Parking Network

Uses static routing and VLSM to provide controlled communication and efficient IP address allocation across multiple routers.


## Key Objectives

* Design a complex smart-city network infrastructure
* Segment departments using VLANs
* Enable inter-VLAN communication
* Implement secure network administration
* Provide redundancy and loop prevention
* Automate IP address assignment
* Implement static and dynamic routing
* Improve network scalability and reliability

## Results

The implemented topology provides structured communication between the different smart-city sectors while demonstrating networking concepts including segmentation, routing, redundancy, security, and automated network management.
